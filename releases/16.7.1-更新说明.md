# c001apk-flutter-hanhua 16.7.1 更新说明

## 一、回帖表情输入修复（16.7.0 已完成，本版保留）

插入表情后再打字，表情会变成 `[疑问推荐]` 这类字面文字、退格删不掉、光标错位。

根因：旧实现把 `[墨镜滑稽]` 整串 token 写进 `text`（6 个字符），再用 `WidgetSpan` 画成图片（渲染只占 1 格），文本长度与渲染长度不守恒；输入法组词时渲染退回纯文本，表情立刻露出字面，光标/选区/退格全按 6 个字符算。

修法：表情改为单字符占位编码（PUA 区 U+E000..U+F8FF），`text` 与渲染严格 1:1；组词阶段只给组词区间加下划线，不再整体退回纯文本；发送时 `outboundText` 解码回 `[名字]`。

## 二、浏览历史 WebDAV 同步（本版新增）

- 新增 `lib/logic/backup/history_cloud_sync.dart`，独立文件 `c001apk_history_backup.json`，不碰全量备份（`c001apk_backup_v10.json`）和收藏备份（`c001apk_fav_backup.json`）。
- 每次进入「历史记录」页即自动双向同步：拉云端 → 与本地按键（feed id）并集合并 → 写回本地与云端，多设备互开一次即可对齐。
- 历史页工具栏新增「通过 WebDAV 同步历史」按钮，可手动触发。
- 合并上限 2000 条，按浏览时间倒序裁剪，避免云端文件无限膨胀。
- 删除语义：单条删除会写墓碑并立刻推云端；「清空全部」会同时清空云端，避免下次进入又从云端回灌（确认弹窗已注明会波及其他设备）。
- WebDAV 配置沿用设置里已有的 `webdav_url` / `webdav_user` / `webdav_pass`，与收藏同步共用；未配置时自动跳过，不弹任何提示。

## 四、自测建议

1. 设备 A 浏览几条帖子 → 进「历史记录」看到自动同步提示 → 设备 B 进「历史记录」应看到同样条目；
2. 设备 A 删一条历史 → 设备 B 再进历史页，该条不再回灌；
3. 设备 A「清空全部」→ 设备 B 同步后应为空；
4. 回帖插入表情 → 拼音打字（未上屏）→ 移光标 → 连续退格，表情始终是图片且能整颗删除。
